# Changelog

## 0.1.1

No change to the grammar. The readme — which Open VSX renders as the
listing page — now gives both ways to install, and records why there is
no Visual Studio Marketplace listing.

## 0.1.0

First release. Syntax highlighting, bracket and comment handling, and
snippets for `.sn` and `.sni` files.

Covers every keyword and intrinsic the compiler knows, plus the three
constructs particular to Soliton: units of measure on types and
literals, `requires`/`ensures` contracts with `result`, and `uses`
effect clauses.
